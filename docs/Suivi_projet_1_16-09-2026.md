# Suivi de projet n°1 — 16/09/2026

**Projet :** Une vie de fourmi  
**Équipe :** Romain, Lisa, Yannis  
**Soutenance :** dans une semaine — présentation totale d'environ 5 minutes

## Où on en est aujourd'hui

Aujourd'hui, on a surtout avancé sur la partie technique et sur la structure générale du projet.

On a :

- compris le problème et les règles de déplacement des fourmis ;
- modélisé la fourmilière sous forme de graphe avec des salles et des tunnels ;
- créé le programme Python principal avec `ants.py`, `main.py` et `visualization.py` ;
- mis en place un algorithme qui cherche le nombre minimum d'étapes pour faire arriver toutes les fourmis au dortoir ;
- pris en compte la capacité des salles et les déplacements simultanés ;
- ajouté plusieurs cas de test ;
- généré les sorties demandées : étapes de déplacement, graphe, matrice d'adjacence et animation ;
- créé le repository GitHub et organisé tous les fichiers du projet ;
- commencé à préparer les supports de soutenance : présentation, script oral et fiche de révision.

## Ce qu'on a vérifié

Le cas simple du sujet fonctionne bien : les 3 fourmis arrivent au dortoir en 3 étapes.

On a également lancé les tests automatiques pour vérifier que les capacités des salles sont respectées et que toutes les fourmis arrivent bien dans `Sd`.

## Ce qu'il reste à faire

Avant la soutenance, il nous reste surtout à :

- refaire une dernière vérification du projet complet ;
- s'assurer que les fichiers officiels du sujet sont bien compatibles avec notre programme ;

- se répartir clairement les parties entre Romain, Lisa et Yannis ;
