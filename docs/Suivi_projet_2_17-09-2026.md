Demain, on passe surtout de la phase de développement à la phase de finalisation.

- relancer le projet sur les différents cas de test ;

- réduire le discours aux idées essentielles pour respecter les 5 minutes ;

## Répartition prévue pour la soutenance

On garde une présentation très courte avec une répartition simple :

- **Romain :** présenter rapidement le problème et la modélisation en graphe ;
- **Lisa :** expliquer simplement notre idée pour trouver le minimum d'étapes ;
- **Yannis :** montrer le résultat, les tests et conclure.

L'objectif n'est pas d'expliquer tout le code ligne par ligne, mais de montrer qu'on comprend le problème, notre solution et le résultat obtenu.

À la fin de cette étape, on veut avoir :

- un projet stable et testé ;
- un GitHub propre ;
- une présentation terminée ;
- un discours de 5 minutes maximum ;
- chacun capable d'expliquer sa partie sans lire tout le texte.
