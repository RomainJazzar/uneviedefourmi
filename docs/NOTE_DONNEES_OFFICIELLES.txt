Le PDF du sujet contient un lien Google Drive « à récupérer ici » vers les fourmilières officielles :
https://drive.google.com/file/d/1aqw-axjXcT4Gm_0WOk9yzeYP4JX3Z2dI/view?usp=sharing

Le lien est identifié, mais son contenu n'a pas pu être téléchargé automatiquement dans l'environnement de génération.
Le programme a donc été conçu avec un parseur tolérant et trois cas de test fournis.

Pour valider à 100 % contre le jeu officiel :
1. télécharger le fichier depuis ce lien ;
2. placer les fichiers texte dans inputs/ ;
3. lancer `python main.py inputs/NOM_DU_FICHIER.txt`.

Si le format officiel diffère légèrement, seul le parseur de ants.py devra être ajusté ; l'algorithme et les visualisations restent valides.
